## 🛠️ Tech Stack & Architecture

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS with custom cyber color palettes, glow shadows, and digital grid textures
- **3D Visualization:** Three.js interactive holographic sphere with gyroscopic rings, wireframe core, and particle nodes
- **Motion:** Framer Motion for smooth section reveals, category filter layouts, and modal transitions
- **Icons:** Lucide React
- **Typography:** Orbitron, Space Grotesk, JetBrains Mono

## 🏃 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
